OSE Character Sheets is a full party-roster character sheet extension for Old-School Essentials (Ascending AC variant), matching the two-column layout of the official AAC character sheet.

## Features

- Full two-column sheet: identity, ability scores with modifiers, saving throws, combat, weapons
- Class Features for Cleric, Magic-User, and Thief, including a growable Memorized Spells list, a level-chaptered Magic-User Spellbook, and a full spell-list reference
- Inventory in all three OSE modes: Basic, Detailed (with running coin-weight totals), and Item-Based (the real Unencumbering/Equipped/Packed slot table)
- Every rollable stat is clickable and rolls through Dice+ when it's in the room, with an honest local fallback when it isn't
- Right-click a token to assign it to a character - portraits sync automatically, and HP/AC push to Stat Bubbles for D&D
- GM-only hidden characters: NPCs the GM marks hidden never appear in a player's party list

## Usage

Click the extension's action icon to open the party roster. Add a character, then click into their sheet to fill it out. GMs can right-click a token on the map and choose "Assign to PC/NPC" to link that token's portrait to a character.
